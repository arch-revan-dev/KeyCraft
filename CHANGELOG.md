# Changelog

Все заметные изменения в **KeyCraft** документируются в этом файле в формате [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [0.1.0] — 2026-11-26

Первый публичный релиз **KeyCraft** для Windows 11 (x64).

### Добавлено
- **Ядро (`crates/core-engine`):**
  - Встроенные офлайн-словари FST (`48 676` RU + `48 283` EN слов) и таблицы биграмм/триграмм (~1.03 МБ, без сетевых загрузок).
  - Мгновенное автопереключение раскладки `RU ↔ EN` с сохранением регистра, поддержкой апострофов (`дуеэы` → `let's`), `ё`, пунктуационных клавиш (`k.,k.` → `люблю`, `[jhjij` → `хорошо`), исправлением случайного CapsLock (`пРИВЕТ` → `Привет`) и правилом частотного доминирования для коротких слов (`ye lf nen` → `ну да тут`).
  - Детерминированная защита от ложных срабатываний (URL, пути к файлам, email, `camelCase`/`PascalCase`/`snake_case`, цифры, CLI-флаги, смешанные скрипты).
  - Офлайн-исправление опечаток (`DL = 1`) с 2D-матрицей соседних клавиш QWERTY/ЙЦУКЕН и парами безударных русских гласных (`сматришь` → `смотришь`, `чта` → `что`, `дила` → `дела`).
  - Постфактум-замена одиночного спецсимвола (`№ ↔ #`, `" ↔ @`, `; ↔ $`), отмена последнего исправления одной клавишей и детерминированное автообучение (автозащита после 2–4 отмен).
  - Пользовательский словарь (поиск, фильтры, импорт/экспорт JSON) и автоподмены (мультитриггеры, `Space`/`Tab`/`Instant`, кросс-раскладочный режим).
  - Циклическая смена регистра, автокапитализация предложений и умное продолжение списков (`1. `, `1) `, `- `, `• `, `* `) с выходом по повторному `Enter`.
  - Покрытие **72 unit-тестами**, включая проверку латентности `< 2 мс`.
- **Системный слой Windows 11 (`crates/platform`) и демон (`src-tauri`):**
  - Низкоуровневые хуки `WH_KEYBOARD_LL` / `WH_MOUSE_LL` с антирекурсивным маркером `dwExtraInfo`.
  - Фоновый COM-поток `UIAutomation` для автоматической блокировки в полях паролей (`UIA_IsPasswordPropertyId`), правил по приложениям и фиксации стартовой раскладки.
  - Захват виртуального рабочего стола (DXGI Desktop Duplication + DPI-aware GDI `BitBlt`) и границ окон через DWM.
  - Нативный Win32 layered-бейдж раскладки у каретки (700 мс) и нативное always-on-top окно закреплённого скриншота без WebView2.
  - Динамическая иконка трея (`RU` / `EN` / Пауза), ленивое создание и полное уничтожение (`window.destroy()`) WebView2 при закрытии настроек (`4.28 МБ` Private RAM в фоне).
  - Кроссплатформенные каркасы `PlatformBackend` для macOS 14+ и Linux (X11/Wayland).
- **Интерфейс (`ui/`, Svelte 5 + TypeScript + Design Tokens CSS):**
  - 8 разделов настроек в светлой (*Warm Studio Paper*) и тёмной (*Deep Tactile Graphite*) темах, реалистичный компонент записи горячих клавиш `<kbd>`, встроенная песочница «Тест-драйв» с трассировкой латентности.
  - Оверлей скриншотера с лупой-прицелом, плашкой `W × H`, стрелками, фигурами, маркером, текстом, нумерованными шагами `1/2/3`, пикселизацией, 2-проходным Gaussian Blur и стеком Undo/Redo.
