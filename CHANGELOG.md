# Changelog

Все заметные изменения в **KeyCraft** документируются в этом файле в формате [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [0.1.7] — 2026-11-26

### Исправлено
- **Повторное срабатывание после отмены двойным `Backspace`:** после отката автопереключения раскладки, исправления опечатки, автоподмены (включая мгновенные сниппеты) или автокапитализации через двойной `Backspace` последующее нажатие `Space` / `Tab` / `Enter` (в том числе после знаков препинания вроде `,` или `.`) больше не заменяет восстановленное слово повторно.
- Добавлены 3 unit-теста на сценарии отмены двойным `Backspace` с последующим `Space` / пунктуацией / `Enter` (всего **83 unit-теста**).

## [0.1.6] — 2026-11-26

### Исправлено и добавлено
- **Двухуровневый перехват `PrintScreen` (`WH_KEYBOARD_LL` + `RegisterHotKey`) на Windows 11 23H2/24H2:**
  - `WH_KEYBOARD_LL` теперь перехватывает и подавляет `VK_SNAPSHOT` (как по `WM_KEYDOWN`/`WM_SYSKEYDOWN`, так и для клавиатур, отправляющих только `WM_KEYUP`/`WM_SYSKEYUP`) **до того**, как системный обработчик Ножниц Windows 11 получит нажатие — поэтому `PrintScreen`, `Alt+PrintScreen` и `Ctrl+PrintScreen` запускают KeyCraft без всплывающих Ножниц даже без перезагрузки.
  - `RegisterHotKey` сохранён вторым слоем для кастомных не-PrintScreen хоткеев и окон с правами администратора (UIPI), с дебаунсом 350 мс против двойного срабатывания.
- **Тумблер «Отключить перехват PrintScreen в Ножницах Windows 11» в разделе «Скриншотер»:** в один клик снимает или возвращает системную настройку `HKCU\Control Panel\Keyboard\PrintScreenKeyForSnippingEnabled` (`0` / `1`) с рассылкой `WM_SETTINGCHANGE` (`HWND_BROADCAST`), а при активном системном перехвате показывает ненавязчивое уведомление.

## [0.1.5] — 2026-11-26

### Исправлено
- **Надёжный перехват `PrintScreen`, `Alt+PrintScreen` и `Ctrl+PrintScreen` через Win32 `RegisterHotKey`:** глобальные хоткеи скриншотера переведены с `WH_KEYBOARD_LL` на выделенный поток `RegisterHotKey` (`WM_HOTKEY`). Теперь сочетания с `PrintScreen` работают на уровне ядра Windows 11 — включая случаи, когда в фокусе окно с правами администратора (UIPI), без пропуска `WM_KEYDOWN` и без всплывающих Ножниц Windows. При отключении скриншотера хоткеи мгновенно снимаются через `UnregisterHotKey`.
- **Запись `PrintScreen` в редакторе горячих клавиш (`KeyRecorder`):** добавлена обработка `keyup` для `PrintScreen`, так как WebView2 в Windows отправляет эту клавишу только по отпусканию.

## [0.1.4] — 2026-11-26

### Добавлено
- **Отмена замены двойным `Backspace` (опциональный тумблер в «Раскладка и опечатки»):** после автозамены (`привет |`) первый `Backspace` удаляет пробел (`привет|`), а второй `Backspace` впритык к слову откатывает замену (`ghbdtn|`), возвращает исходную раскладку и засчитывает отмену в локальное автообучение. Поддерживается также в песочнице «Тест-драйв».
- Добавлены 4 unit-теста на сценарии отмены по `Backspace` (всего **80 unit-тестов**).

## [0.1.3] — 2026-11-26

### Исправлено
- **Кристально чёткие скриншоты на HiDPI (125% / 150% / 200%):** буфер `<canvas>` и экспорт PNG теперь работают строго в нативных физических пикселях экрана (`naturalWidth × naturalHeight`, 1:1 `drawImage` без даунскейла и мыла), а лупа и плашка `W × H` отображают реальные физические координаты.
- **Точный захват активного окна:** координаты `DWMWA_EXTENDED_FRAME_BOUNDS` корректно переводятся в логические координаты оверлея с учётом `devicePixelRatio` — рамка активного окна больше не смещается и не обрезается.
- **Перехват `PrintScreen` без Ножниц Windows:** при включённом скриншотере низкоуровневый хук `WH_KEYBOARD_LL` перехватывает и подавляет `VK_SNAPSHOT` (key-down и key-up), чтобы встроенный инструмент Windows не перекрывал KeyCraft. При выключении тумблера скриншотера `PrintScreen` свободно передаётся системе.

### Добавлено
- **Сброс по умолчанию на всех уровнях:**
  - Индивидуальная кнопка сброса (`RotateCcw`) прямо рядом с каждой изменённой горячей клавишей + очистка сочетания клавишей `Backspace` в режиме записи.
  - Кнопка **«Сбросить клавиши»** в разделе *Горячие клавиши*.
  - Кнопка **«По умолчанию»** в липком заголовке каждого раздела настроек (и **«Сбросить всё»** в разделе *Тест-драйв и система*).

## [0.1.2] — 2026-11-26

### Добавлено
- **Полное отключение скриншотера (`screenshot.enabled`):** добавлен главный тумблер в разделе «Скриншотер». При выключении KeyCraft полностью прекращает перехват `PrintScreen` и скрывает пункты скриншотера из трея — ноль конфликтов со встроенными Ножницами Windows.
- **Исправление «двух-трёх заглавных» (залипший Shift):** слова вроде `ЧТОбы` → `Чтобы`, `ПРивет` → `Привет`, `HEllo` → `Hello` автоматически исправляются при точном совпадении со словарём (аббревиатуры `США`, `API` и `HttpClient` / `IPAddress` не затрагиваются).

### Исправлено
- **Белый экран в оверлее скриншотера:** устранена блокировка CORS при загрузке кадра в `<canvas>` (добавлен IPC `get_capture_image_data_url` + заголовок `Access-Control-Allow-Origin: *` для `keycraft-capture://`), теперь снимок экрана отображается мгновенно и без искажений, включая лупу и размытие.
- **Защита коротких русских аббревиатур (`пк`, `тк`, `вк`, `тг`, `лс`, `хз`, `др`, `тд`):** добавлены в базовый словарь и введён порог ранга ≤ 400 для 2-буквенных переключений, чтобы `пк` никогда не превращалось в `gr`, а `тк` — в `nr`.

## [0.1.1] — 2026-11-26

### Исправлено (Стабильность и отзывчивость Windows 11)
- **Устранено зависание `AppHangB1` / `AppHangXProcB1`:** убран синхронный реентрантный вызов `window.destroy()` внутри `WindowEvent::CloseRequested` (теперь WebView2 корректно закрывается и выгружается без взаимной блокировки `WM_CLOSE`).
- **Устранён дедлок трея и UI-потока:** все обновления иконки трея перенесены на главный UI-поток через `run_on_main_thread`, а пересборка `HMENU` выполняется только при переключении паузы (не при каждой смене раскладки `RU`/`EN`).
- **Устранён системный лаг при вводе:**
  - В окне бейджа раскладки у каретки (`badge.rs`) добавлена прокачка Win32-очереди сообщений (`PeekMessageW`/`DispatchMessageW`), чтобы DWM не помечал всплывающий бейдж как зависшее окно.
  - В `focus.rs` добавлен debounce 120 мс для `EVENT_OBJECT_FOCUS` и убран медленный кросс-процессный COM-вызов `CurrentName()` из `UIAutomation`.
  - В `hook.rs` убрана лишняя пересылка событий `WM_KEYUP` для обычных клавиш (отправляются только одиночные нажатия модификаторов `LAlt`/`RAlt`).
- **Устранено зависание при захвате экрана:** команда `trigger_screenshot` сделана асинхронной с захватом экрана в фоновом потоке; основным методом захвата стал быстрый DPI-aware GDI `BitBlt` (без зависаний DXGI Desktop Duplication на гибридной графике Intel Xe/Iris).

### Добавлено
- **Диагностический журнал без кейлоггинга (`%APPDATA%\KeyCraft\KeyCraft\logs\keycraft.log`):** ротация при 128 КБ + обработчик паник (`std::panic::set_hook`). Записывает исключительно жизненный цикл окон и системные ошибки — **никогда** не логирует клавиши, слова, заголовки окон или буфер обмена.

## [0.1.0] — 2026-11-26

Первый публичный релиз **KeyCraft** для Windows 11 (x64).

### Добавлено
- **Ядро (`crates/core-engine`):**
  - Встроенные офлайн-словари FST (`48 676` RU + `48 283` EN слов) и таблицы биграмм/триграмм (~1.03 МБ, без сетевых загрузок).
  - Мгновенное автопереключение раскладки `RU ↔ EN` с сохранением регистра, поддержкой апострофов (`дуеэы` → `let's`), `ё`, пунктуационных клавиш (`k.,k.` → `люблю`, `[jhjij` → `хорошо`), исправлением случайного CapsLock (`пРИВЕТ` → `Привет`) и правилом частотного доминирования для коротких слов (`ye lf nen` → `ну да тут`).
  - Детерминированная защита от ложных срабатываний (URL, пути к файлам, email, `camelCase`/`PascalCase`/`snake_case`, цифры, CLI-флаги, смешанные скрипты).
  - Офлайн-исправление опечаток (`DL = 1`) с 2D-матрицей соседних клавиш QWERTY/ЙЦУКЕН и парами безударных русских гласных (`сматришь` → `смотришь`, `чта` → `что`, `дила` → `дела`).
  - Постфактум-замена одиночного спецсимвола (`№ ↔ #`, `" ↔ @`, `; ↔ $`), отмена последнего исправления одной клавишей и детерминированное автообучение (автозащита после 2–4 отмен).
  - Пользовательский словарь (поиск, фильтры, импорт/экспорт JSON) и автоподмены (мультитриггеры, `Space`/`Tab`/`Instant`, кросс-раскладочный режим).
  - Циклическая смена регистра, автокапитализация предложений и умное продолжение списков (`1. `, `1) `, `- `, `• `, `* `) с выходом по повторному `Enter`.
  - Покрытие **72 unit-тестами**, включая проверку латентности `< 2 мс`.
- **Системный слой Windows 11 (`crates/platform`) и демон (`src-tauri`):**
  - Низкоуровневые хуки `WH_KEYBOARD_LL` / `WH_MOUSE_LL` с антирекурсивным маркером `dwExtraInfo`.
  - Фоновый COM-поток `UIAutomation` для автоматической блокировки в полях паролей (`UIA_IsPasswordPropertyId`), правил по приложениям и фиксации стартовой раскладки.
  - Захват виртуального рабочего стола (DXGI Desktop Duplication + DPI-aware GDI `BitBlt`) и границ окон через DWM.
  - Нативный Win32 layered-бейдж раскладки у каретки (700 мс) и нативное always-on-top окно закреплённого скриншота без WebView2.
  - Динамическая иконка трея (`RU` / `EN` / Пауза), ленивое создание и полное уничтожение (`window.destroy()`) WebView2 при закрытии настроек (`4.28 МБ` Private RAM в фоне).
  - Кроссплатформенные каркасы `PlatformBackend` для macOS 14+ и Linux (X11/Wayland).
- **Интерфейс (`ui/`, Svelte 5 + TypeScript + Design Tokens CSS):**
  - 8 разделов настроек в светлой (*Warm Studio Paper*) и тёмной (*Deep Tactile Graphite*) темах, реалистичный компонент записи горячих клавиш `<kbd>`, встроенная песочница «Тест-драйв» с трассировкой латентности.
  - Оверлей скриншотера с лупой-прицелом, плашкой `W × H`, стрелками, фигурами, маркером, текстом, нумерованными шагами `1/2/3`, пикселизацией, 2-проходным Gaussian Blur и стеком Undo/Redo.
